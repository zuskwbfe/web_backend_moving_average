# Periods Catalog API

REST API каталога периодов (месяцы и кварталы). Услуга это период с порядковым номером и количеством дней. Бэкенд на FastAPI, данные в PostgreSQL (ORM SQLAlchemy), фото и видео в MinIO.

## Запуск

1. Поднять сервисы (PostgreSQL, Adminer, MinIO, Redis): `docker compose up -d`
2. Создать файл `.env` (имена переменных):
   `DB_HOST`, `DB_PORT`, `DB_USER`, `DB_PASSWORD`, `DB_NAME`, `MINIO_ENDPOINT`, `MINIO_ACCESS_KEY`, `MINIO_SECRET_KEY`, `MINIO_BUCKET`, `MINIO_SECURE`; для Redis по умолчанию `REDIS_HOST=localhost`, `REDIS_PORT=6379`, время жизни сессии `SESSION_TTL_SECONDS=3600`, имя куки `SESSION_COOKIE_NAME=session_id`
3. Применить миграции: `alembic upgrade head`
4. Запустить сервер: `python main.py` (http://127.0.0.1:8000). Описание методов в Swagger: http://127.0.0.1:8000/docs

## Методы API

Все адреса начинаются с `/api`. Ответы в формате JSON без обёртки `status` и `message`: результат определяет код ответа. Авторизация построена на сессиях: после входа сервер создаёт сессию в Redis и выставляет HttpOnly-куку `session_id` (время жизни 3600 секунд). Методы 3-7 и 10 доступны только после входа, без сессии они возвращают `401`. Список и лента (методы 1 и 2) доступны и гостю. Куку session_id берут из F12 → Application → Cookies и добавляют в заголовок Cookie каждого запроса создателя.

Системные поля (`id`, статус, создатель, даты создания и формирования) вычисляет сервер. Если клиент пришлёт их в теле запроса, ответ будет `422`.

### Домен periods (услуги)

| № | Метод | Адрес | Что делает | Тело запроса | Успех | Ошибки |
|---|---|---|---|---|---|---|
| 1 | GET | `/api/periods?min_days=` | Список опубликованных периодов с фильтром по минимальному количеству дней | нет | 200 | 422 |
| 2 | GET | `/api/periods/feed` и `/api/periods/feed/{id}?next=true` | Лента: одна опубликованная услуга. Без id первая, с id эта, с id и `next=true` следующая по порядку (после последней первая) | нет | 200 | 404 |
| 3 | GET | `/api/periods/draft` | Черновик текущего пользователя (не более одного), id не указывается | нет | 200 | 401, 404 |
| 4 | POST | `/api/periods` | Создание черновика: название, фото и короткое видео как файлы | form-data: `title`, `image`, `video` | 201 | 400, 401, 409, 422 |
| 5 | PUT | `/api/periods/{id}` | Публикация черновика (статус `draft` → `published`) | JSON: `description`, `order_number`, `days_count` | 200 | 401, 403, 404, 409, 422 |
| 6 | DELETE | `/api/periods/{id}` | Мягкое удаление своего периода (строка остаётся в БД, статус `deleted`) | нет | 204 | 401, 403, 404 |
| 7 | POST | `/api/periods/{id}/like` | Лайк от текущего пользователя: `like` 1 ставит, 0 отменяет | JSON: `like` | 200 | 401, 404, 422 |

### Домен users (пользователи)

| № | Метод | Адрес | Что делает | Тело запроса | Успех | Ошибки |
|---|---|---|---|---|---|---|
| 8 | POST | `/api/users` | Регистрация. Пароль сохраняется только в виде хэша | JSON: `login`, `password` | 201 | 409, 422 |
| 9 | POST | `/api/users/login` | Аутентификация: проверяет пароль, создаёт сессию в Redis и выставляет куку `session_id` | JSON: `login`, `password` | 200 | 401, 422 |
| 10 | POST | `/api/users/logout` | Деавторизация: удаляет сессию из Redis и куку | нет (кука `session_id`) | 204 | 401 |

### Коды ответов

| Код | Когда |
|---|---|
| 200 | чтение, публикация, лайк |
| 201 | черновик или пользователь создан |
| 204 | удаление, выход (тела нет) |
| 400 | неверный тип или пустой файл |
| 401 | нет сессии или она истекла (требуется вход) |
| 403 | чужая услуга |
| 404 | не найдено или уже удалено (удалённые клиенту не передаются) |
| 409 | второй черновик, повторная публикация, занятый логин |
| 422 | ошибка данных: лишнее поле, значение вне диапазона, нет файла |

### Ограничения полей запроса

| Поле | Ограничение |
|---|---|
| `title` | 1-100 символов |
| `image` | файл `image/jpeg`, `image/png` или `image/webp` |
| `video` | файл `video/mp4` или `video/webm` |
| `description` | 1-500 символов |
| `order_number` | целое, не меньше 1 |
| `days_count` | целое, от 1 до 366 |
| `like` | только 0 или 1 |
| `login` | 3-50 символов, уникальный |
| `password` | 6-64 символа |

### Поля ответов

Список (метод 1):

```json
[
  {
    "id": 1,
    "title": "Октябрь",
    "days_count": 31,
    "image_url": "http://localhost:9000/periods/3f2a9c1e5b7d4a8f9e0c1d2b3a4f5e6d.png",
    "likes_count": 5,
    "is_mine": 1
  }
]
```

Лента (метод 2):

```json
{
  "id": 1,
  "title": "Октябрь",
  "description": "Отчётный период — октябрь 2026 года",
  "order_number": 10,
  "days_count": 31,
  "video_url": "http://localhost:9000/periods/8b1c2d3e4f5a6b7c8d9e0f1a2b3c4d5e.mp4",
  "likes_count": 5,
  "is_liked": 0
}
```

Черновик, результат создания и публикации (методы 3, 4, 5): `id`, `title`, `description`, `order_number`, `days_count`, `image_url`, `video_url`. Пока поля не заполнены (до публикации), `description`, `order_number` и `days_count` приходят как `null`.

| Поле | Значение |
|---|---|
| `is_mine` | 1, если создатель услуги это текущий пользователь. По нему интерфейс решает, показывать ли кнопку «Удалить» |
| `is_liked` | 1, если текущий пользователь уже поставил лайк. По нему интерфейс рисует нажатое сердце, а при нажатии отправляет `like: 0` или `like: 1` |
| `likes_count` | количество лайков услуги |
| `image_url`, `video_url` | полный адрес файла в MinIO |

## Статусы услуги

| Статус | Значение |
|---|---|
| `draft` | черновик, у пользователя не более одного |
| `published` | опубликована, видна всем |
| `deleted` | удалена (мягкое удаление), клиенту не передаётся |

Переходы: `draft` → `published` (метод 5), `draft` или `published` → `deleted` (метод 6). Возврат в черновик невозможен.

## Файлы

Фото и видео загружаются в MinIO (бакет `periods`). Имя файла генерируется на латинице, вида `<uuid>.<расширение>`. В полях `image_url` и `video_url` БД хранится это имя, полный адрес собирается при формировании ответа.

### users

|---|---|---|---|

| `video_url` | VARCHAR(255) | да | имя файла видео |
| `order_number` | INTEGER | нет | порядковый номер периода, заполняется при публикации |

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|

## Сессии и Redis

Сессия хранится в Redis как хэш по ключу `session:<идентификатор>` с полями `user_id` и `login`. Идентификатор непредсказуемый (`secrets.token_urlsafe(32)`), он же значение куки `session_id`. Через `SESSION_TTL_SECONDS` (3600 секунд) ключ удаляется автоматически.

Скрипт `logins.lua` возвращает логины пользователей всех активных сессий. Запуск: скопировать скрипт в контейнер `docker cp logins.lua periods_redis:/logins.lua`, затем `docker exec periods_redis redis-cli --eval /logins.lua`.

## Postman

Коллекция методов лежит в файле `Periods api.postman collection.json`. Импорт: Postman → Import → выбрать файл. Куку `session_id` после запроса входа Postman подставляет в следующие запросы сам.
